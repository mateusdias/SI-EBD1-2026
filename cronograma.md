# Cronograma da Disciplina — Estudos de Banco de Dados I (EBD-1)

Este cronograma está organizado por **blocos mensais**, alinhando **conteúdo teórico**, **tecnologias trabalhadas** e **atividades práticas**, respeitando o Plano de Ensino da disciplina.

---

## Bloco 1 — Fundamentos de SGBDs e Modelo Entidade-Relacionamento
**Período:** Agosto

### Conteúdos
- Dicionário de Dados e documentação mínima sobre dados
- Arquitetura de sistemas gerenciadores de bancos de dados
- Conceitos fundamentais de bancos de dados relacionais
- Modelo de Entidades e Relacionamentos
- Papel da modelagem de dados no design de software

### Tecnologias e Ferramentas
- Sistemas gerenciadores de bancos de dados relacionais
- Ferramentas de modelagem de dados

### Atividades
- Exercício avaliativo 1

## Bloco 2 — Modelagem Conceitual, Mapeamento Relacional e Integridade
**Período:** Setembro

### Conteúdos
- Entidades, atributos e identificadores
- Relacionamentos, cardinalidade e obrigatoriedade
- Generalização, especialização e agregação
- Mapeamento do modelo conceitual para o modelo relacional
- Tabelas, linhas, colunas, chaves primárias e estrangeiras
- Normalização e integridade

### Tecnologias e Ferramentas
- Ferramentas de modelagem de dados
- SGBDs relacionais

### Atividades
- Exercício avaliativo 2

## Bloco 3 — Cálculo Relacional, Álgebra Relacional e SQL
**Período:** Outubro

### Conteúdos
- Elementos de cálculo relacional
- Elementos de álgebra relacional
- Linguagem SQL
- DDL e comandos fundamentais
- Consultas e manipulação de dados

### Tecnologias e Ferramentas
- SQL
- Oracle Database

### Atividades
- Exercício avaliativo 3

## Bloco 4 — SQL Avançado e Recursos Nativos dos SGBDs
**Período:** Novembro

### Conteúdos
- SQL avançado
- Funções
- Stored procedures
- Triggers
- Mecanismos de proteção, recuperação e segurança
- Controle de concorrência

### Tecnologias e Ferramentas
- Oracle Database
- Recursos nativos de SGBDs relacionais

## Bloco 5 — Finalização do Semestre
**Período:** Dezembro

### Conteúdos
- Entrega das notas finais e encerramento do semestre.
