# Estudos de Banco de Dados I (EBD-1)

Repositório oficial da disciplina **Estudos de Banco de Dados I (EBD-1)**, ministrada no curso de **Sistemas de Informação** da **Pontifícia Universidade Católica de Campinas (PUC-Campinas)**.

Este repositório tem como objetivo centralizar materiais didáticos, conteúdos teóricos, atividades práticas, experimentos e documentos de referência relacionados ao estudo de **bancos de dados relacionais**, modelagem de dados, SQL e recursos fundamentais de sistemas gerenciadores de bancos de dados.


## Informações Gerais

- **Curso:** Sistemas de Informação  
- **Disciplina:** Estudos de Banco de Dados I  
- **Professor:** Prof. Me. Mateus Dias  
- **Ano:** 2026  

## Objetivos da Disciplina

Ao longo da disciplina, o estudante será capaz de:

- Compreender a arquitetura de sistemas gerenciadores de bancos de dados  
- Modelar dados por meio do modelo Entidade-Relacionamento  
- Mapear modelos conceituais para o modelo relacional  
- Aplicar regras de normalização e integridade  
- Utilizar SQL e recursos nativos de SGBDs relacionais  
- Analisar mecanismos de proteção, recuperação, segurança e controle de concorrência  

## Conteúdos Abordados

Entre os principais temas trabalhados na disciplina, destacam-se:

- Arquitetura de sistemas gerenciadores de bancos de dados  
- Modelo de Entidades e Relacionamentos  
- Modelagem conceitual, abstração, design e mapeamento de dados  
- Modelo relacional, tabelas, chaves, tipos de dados e relacionamentos  
- Normalização e integridade  
- Cálculo e álgebra relacional  
- SQL, DDL, funções, stored procedures, triggers e outros recursos de SGBDs  
- Proteção, recuperação, segurança e controle de concorrência  

## Tecnologias Utilizadas

Durante o semestre, serão exploradas, de forma prática ou conceitual, as seguintes tecnologias e recursos:

- SQL  
- Sistemas gerenciadores de bancos de dados relacionais  
- Oracle Database  
- Ferramentas de modelagem de dados
